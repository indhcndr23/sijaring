# Sipanda

## Contribution

1. Clone the repository
```
git clone -b development https://github.com/Diskominfo-Magelang/sipanda.git
```

2. Buat branch baru

```
git checkout -b <branch-name>
```

3. Modifikasi kode
4. "Commit" perubahan & "Push" branch kemudian lakukan "Pull request"

### PERHATIAN!!

Untuk meminimalisir kesalahan, jangan push perubahan ke branch development. Selalu gunakan Pull Request untuk menggabungkan code.
